# SotE (cheats) for phone

Playable copy of Shadow of the Eagles 0.6.2 with cheat mode, for personal use.
Rebuild: run `Shadow of the Eagles - source/inject_cheats.py` (writes index.html here), then commit and push.
Play upright or sideways. Cheats: Settings > Cheats, then tap stats on the left panel.
Fits the screen: a small script after the viewport meta in `index.html` sizes the page so the 1600x900 game fits without scrolling. If you rebuild, carry that block over (the inject script doesn't add it yet).
For true full screen on iPhone: Safari > Share > Add to Home Screen, then open it from the home screen.
